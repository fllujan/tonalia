# Third-party dependencies

Every dependency added to Tonalia is listed here with its license. All must be compatible with **AGPL-3.0**. Models or libraries under "non-commercial" licenses are not allowed in the default configuration.

This hand-kept table is the record of *why* each dependency is here. The exact list that ships in each build — every transitive Python, npm and Cargo package with its version and license text — is generated by `scripts/third_party.py` (run by `scripts/build_engine.py`, or `./scripts/gen-third-party`) into the bundled `licenses/` folder: `third-party.json` (Settings → About → "Third-party licences") and `THIRD-PARTY-NOTICES.txt`. The generator fails when a shipped package has an unknown or AGPL-incompatible license; unclear metadata is resolved by hand in `licenses/overrides.json`, and non-package components (FFmpeg, Rubber Band, libsndfile, Demucs) are described in `licenses/bundled.json`.
